# Decision Log

Architecture and pattern decisions for Cosmonaut. Check here before making decisions
that affect project-wide patterns.

## Format

Each decision is a separate markdown file named `NNNN-short-description.md`:

```markdown
# NNNN — Short Title

**Date:** YYYY-MM-DD
**Status:** accepted | superseded by NNNN | rejected
**Context:** What prompted this decision
**Decision:** What was decided
**Consequences:** What follows from this decision
```

## Why this exists

Decisions get made in conversations and forgotten. When a future session encounters
the same question, it re-derives the answer — sometimes differently. This log
prevents that drift. If you disagree with a past decision, don't silently override
it. Reference the original, explain what changed, and create a new record.
